## Key Features Demonstrated

| Feature | Description |
|---------|-------------|
| 🎓 **Coaching Personality** | Polite yet assertive, adapts to performance |
| 🔄 **Multiple Attempts** | Up to 3 tries per question |
| 💡 **Smart Hints** | Activate automatically after wrong answers |
| 📊 **Progress Tracking** | Attempts, hints, and performance metrics |
| ✨ **Beautiful UI** | Modern gradient design with smooth animations |
| 🎯 **No Easy Outs** | Students must work through problems |
